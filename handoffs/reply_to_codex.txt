Design
- 8 scenarios: constant, weak_dep, main_like, new_pairs (unseen lag pairs), and_rule, xor3 (3-lag parity), changes (machine drift plus shared flip), size_indep (size regime Markov, independent of wins).
- 4 masks on the same latent episodes and targets: full, recent40_older24, window48, gaps35.
- dev: 8 episodes per scenario (seeds 1000+; 56 to 64 machines per scenario).
  sealed: 40 episodes per scenario (seeds 900000+; 257 to 308 machines per scenario). Disjoint seeds and episodes. 4 to 10 machines per episode.
- Truth schema: query_id, episode_id, scenario, mask, p_0, p_1, p_2, p_5, p_20, outside every data root.
- Metric: summed squared error per query, averaged within each episode, then over episodes per scenario x mask. Paired bootstrap of episode differences (2,000 resamples, 95% CI), labeled WIN / REGRESSION / tie. A pooled reference is included for scale.

Commands
  python run_entry.py --entry <entry.zip> --name <name> --set dev
  python score.py --set dev --entries baseline candidate
